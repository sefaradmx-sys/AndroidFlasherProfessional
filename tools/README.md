# tools/

Esta carpeta incluye los binarios oficiales de ADB y Fastboot (platform-tools) para Windows.

El software los usa automáticamente si no están en el PATH del sistema.

Archivos incluidos en el paquete descargable:
- adb.exe
- fastboot.exe
- AdbWinApi.dll
- AdbWinUsbApi.dll
- libwinpthread-1.dll

Fuente: https://developer.android.com/tools/releases/platform-tools
